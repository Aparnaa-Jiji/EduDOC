# EduDOC

An Automated Framework for Academic Document Compliance and Evaluation.

EduDOC is a web-based application developed using Django that helps educational institutions automate the evaluation of academic documents such as seminar reports, mini projects, and major project reports. The system checks uploaded DOCX files against predefined formatting and compliance guidelines, generates detailed evaluation reports, and provides feedback to students while reducing the manual effort required from faculty.

This project was developed as my MCA final-year project.
